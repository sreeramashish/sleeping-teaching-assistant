01 / The challenge

One TA. Many students. Shared space.

A teaching assistant helps one student at a time and sleeps when nobody needs help. Arriving students wake the TA, or wait in one of N hallway chairs while the TA is busy. If every chair is occupied, they leave and try again later. A mutex protects the chair count; semaphores signal waiting students and TA availability.

The original C program uses three chairs and six student threads by default. Every student needs help twice. Explore different chair counts below.

A concrete example / 3 waiting chairs

Follow one office-hours story.

This example uses the same six students and three numbered chairs as the playground. The schedule is illustrative: browser arrivals happen randomly, but this teaching model calls seated students in arrival order. The original POSIX semaphores do not guarantee FIFO fairness. Turn on Step by step and use Next to read your own run one event at a time.

  1. TA: sleeping. The hallway is empty. The TA waits without spinning. sem_wait(students_sem)
  2. Student 1 arrives and finds the TA sleeping. Student 1 briefly sits on chair 1, checks the count while holding the mutex, then signals the TA. mutex lock/unlock → sem_post(students_sem)
  3. The TA wakes and calls Student 1 from chair 1. That chair becomes free; Student 1 starts getting help. sem_wait(students_sem) → mutex lock/unlock → sem_post(ta_sem) → sem_wait(ta_sem)
  4. While the TA helps Student 1, Students 2, 3 and 4 arrive. They sit on chairs 1, 2 and 3 respectively; now all three hallway chairs are occupied. Each: mutex lock/unlock → sem_post(students_sem)
  5. All chairs full — Student 5 leaves without help. Student 5 programs for a while and retries on a later arrival; the semaphore is not posted for this failed attempt. mutex lock/check/unlock
  6. The TA finishes helping Student 1, then calls the next student. Suppose Student 2 is selected from chair 1: the chair is freed and Student 2 begins help. sem_wait(students_sem) → mutex lock/unlock → sem_post(ta_sem) → sem_wait(ta_sem)
  7. Student 5 retries and takes the newly free chair 1. Student 6 also eventually finds a free chair and is helped; every student returns for a second visit. Repeat the same chair check and semaphore handshake
  8. After both visits, all six students have received help. In an empty hallway the TA sleeps; at final shutdown the last student sends the extra wake-up so the TA can check students_done and go home. mutex lock/unlock → sem_post(students_sem) → sem_wait(students_sem)

In the C listing even the first arrival briefly counts as seated before the TA calls them in. The simulation preserves this visible step instead of silently bypassing the chair.

03 / Under the hood

Three primitives. One coordinated system.

01 / THREADS

Independent students

One TA thread and one thread per student run concurrently. Students program, ask for help twice, and finish. The last student wakes the TA to shut down.

02 / MUTEX

Protect the chairs

chairs_mutex makes checking and updating waiting_students a single critical section. It also guards students_done. Release it before waiting on a semaphore.

03 / SEMAPHORES

Signal, don't spin

students_sem counts seated students and wakes the TA. ta_sem lets the TA call one waiting student in. Both start at zero: no work, no busy waiting.

STUDENT → lock → check / sit → unlock → post(students_sem)
TA → wait(students_sem) → lock → free chair → unlock → post(ta_sem)
STUDENT → wait(ta_sem) → get help → program again or finish

Model boundary: JavaScript's event loop serializes the illustrated critical sections. This visualization treats a help session as one complete interaction. The verbatim C source uses independent random sleeps for TA and student, with no help-completion handshake; it does not enforce identical timing or a FIFO queue. No source fixes have been silently applied.

04 / The implementation

Read the real C program.

Appendix A from the project report. POSIX threads, one mutex, two semaphores.

sleeping_ta.c · C / POSIX
/* * Sleeping Teaching Assistant - POSIX threads, mutex lock, semaphores * Compile: gcc -Wall -pthread sleeping_ta.c -o sleeping_ta * Run: ./sleeping_ta [number_of_students] (default 6) * * Idea: * - students_sem : counts students waiting in hallway chairs (TA sleeps on it when 0) * - ta_sem : TA signals "I am ready" to ONE waiting student * - chairs_mutex : protects the shared counter waiting_students * - 3 chairs in the hallway; if all taken, student leaves and comes back later */ #include <stdio.h> #include <stdlib.h> #include <pthread.h> #include <semaphore.h> #include <unistd.h> #define NUM_CHAIRS 3 #define HELPS_PER_STUDENT 2 /* each student wants help this many times */ sem_t students_sem; /* waiting students (TA sleeps when 0) */ sem_t ta_sem; /* TA available to help one student */ pthread_mutex_t chairs_mutex = PTHREAD_MUTEX_INITIALIZER; int waiting_students = 0; /* occupied chairs (shared, mutex-guarded) */ int total_students = 6; int students_done = 0; /* students who got all their help */ static void pause_random(int max_sec) { /* sleep 1..max_sec seconds */ sleep(1 + rand() % max_sec); } void *ta_thread(void *arg) { (void)arg; while (1) { printf("[TA] No students. TA is sleeping...\n"); sem_wait(&students_sem); /* sleep until a student arrives */ /* a student is waiting (or woke us): take one off the chair */ pthread_mutex_lock(&chairs_mutex); if (students_done >= total_students) { /* shutdown signal */ pthread_mutex_unlock(&chairs_mutex); break; } if (waiting_students > 0) waiting_students--; int left = waiting_students; pthread_mutex_unlock(&chairs_mutex); sem_post(&ta_sem); /* call the student in */ printf("[TA] Helping a student. Chairs occupied now: %d\n", left); pause_random(3); /* helping takes time */ printf("[TA] Finished helping a student.\n"); } printf("[TA] All students done. TA goes home.\n"); return NULL; } void *student_thread(void *arg) { int id = *(int *)arg; int helped = 0; while (helped < HELPS_PER_STUDENT) { printf(" [Student %d] Programming for a while...\n", id); pause_random(5); pthread_mutex_lock(&chairs_mutex); if (waiting_students < NUM_CHAIRS) { waiting_students++; printf(" [Student %d] Needs help. Sat on a chair (%d/%d occupied).\n", id, waiting_students, NUM_CHAIRS); pthread_mutex_unlock(&chairs_mutex); sem_post(&students_sem); /* tell/wake the TA */ sem_wait(&ta_sem); /* wait until TA is ready */ printf(" [Student %d] Getting help from the TA.\n", id); pause_random(3); helped++; printf(" [Student %d] Got help (%d/%d).\n", id, helped, HELPS_PER_STUDENT); } else { pthread_mutex_unlock(&chairs_mutex); printf(" [Student %d] No free chair! Will come back later.\n", id); } } pthread_mutex_lock(&chairs_mutex); students_done++; int all_done = (students_done >= total_students); pthread_mutex_unlock(&chairs_mutex); if (all_done) sem_post(&students_sem); /* wake sleeping TA so it can exit */ return NULL; } int main(int argc, char *argv[]) { if (argc > 1) total_students = atoi(argv[1]); if (total_students < 1) total_students = 1; srand(42); /* change for different runs */ sem_init(&students_sem, 0, 0); sem_init(&ta_sem, 0, 0); pthread_t ta; pthread_t *students = malloc(sizeof(pthread_t) * total_students); int *ids = malloc(sizeof(int) * total_students); pthread_create(&ta, NULL, ta_thread, NULL); for (int i = 0; i < total_students; i++) { ids[i] = i + 1; pthread_create(&students[i], NULL, student_thread, &ids[i]); } for (int i = 0; i < total_students; i++) pthread_join(students[i], NULL); pthread_join(ta, NULL); sem_destroy(&students_sem); sem_destroy(&ta_sem); pthread_mutex_destroy(&chairs_mutex); free(students); free(ids); printf("Simulation finished.\n"); return 0; }

05 / Try it locally

From source to office hours.

Use GCC on Linux with POSIX thread and semaphore support. Pass the student count as an optional argument (default: 6). Every student requests help twice.

macOS does not support the unnamed semaphores used here without changes. Random thread scheduling changes the output order. The browser simulation needs no installation or network dependencies.
